# AI Brain Quick Reference

Purpose:
This folder is the quick-reference pointer index for future agents working in C:\Github\classics.ourstuff.space. It tells agents where to look first, which terms mean what, and how to save durable handoff output into the Local AI Brain.

First move for non-trivial work:
1. Read AGENTS.md.
2. Read project-context/AGENT_ALIGNMENT.md.
3. Run a narrow Local AI Brain context pack.
4. Check project-context/pointers/002_system-map.json for the relevant surface.
5. Read only the smallest canonical file that owns the topic.

Direct PowerShell setup:

$env:LOCAL_AI_BRAIN_HOME = "C:\Github\classics.ourstuff.space\localaibrain\brain"

Useful commands:
- Health: python -m local_ai_brain doctor
- Search: python -m local_ai_brain search --repo "C:\Github\classics.ourstuff.space" --query "<topic>" --limit 10
- Context pack: python -m local_ai_brain context-pack --repo "C:\Github\classics.ourstuff.space" --query "<topic>" --limit 5
- Record handoff/artifact: python -m local_ai_brain record-artifact --json-file "<payload.json>"
- Optimize: python -m local_ai_brain optimize --apply

Key terms:
- Local AI Brain: project-local searchable memory and artifact store under localaibrain.
- Pointer: short durable index entry under project-context/pointers that links terms, surfaces, workflows, and canonical files.
- Context pack: compact Local AI Brain retrieval result used before broad repo scans.
- Proof session: Local AI Brain audit trail showing whether memory retrieval helped.
- Handoff artifact: compact session summary generated by $handoff, saved to OS temp, then recorded into Local AI Brain.
- Grill with docs: planning workflow that checks project language and docs, asks unresolved questions one at a time, and updates glossary/ADR docs only when justified.
- project-context/CONTEXT.md: domain glossary only. Create lazily when a real term is resolved.
- ADR: durable decision record for hard-to-reverse, surprising trade-offs only.

Maintenance rule:
If you add a durable workflow, subsystem, or canonical document, update 002_system-map.json and add a short pointer file if the topic needs more than one sentence.
