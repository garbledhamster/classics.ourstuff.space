# Handoff To Brain Workflow

Goal:
Every $handoff output should remain easy for a fresh agent to find through the project Local AI Brain.

Required behavior:
1. Use $handoff to write the handoff document to the OS temp directory.
2. Redact secrets, credentials, tokens, private account data, and raw PII.
3. Include a suggested skills section.
4. Reference existing plans, ADRs, issues, commits, diffs, and artifacts by path or URL instead of duplicating them.
5. Record the handoff into Local AI Brain with record-artifact.
6. Keep the temp path in the handoff record summary or related_files when useful.

PowerShell template:

$repo = "C:\Github\classics.ourstuff.space"
$env:PYTHONPATH = "$repo\localaibrain\scripts"
$env:LOCAL_AI_BRAIN_HOME = "$repo\localaibrain\brain"
$handoffPath = Join-Path $env:TEMP "classics-handoff-$(Get-Date -Format yyyyMMdd-HHmmss).md"

# Write the $handoff document to $handoffPath first.

$payloadPath = Join-Path $env:TEMP "classics-handoff-payload-$(Get-Date -Format yyyyMMdd-HHmmss).json"
$payload = @{
  artifact_type = "handoff"
  repo_path = $repo
  target_surface = "handoff"
  title = "Session handoff"
  summary = "Session handoff recorded from OS temp into project Local AI Brain."
  body = Get-Content -Raw $handoffPath
  tags = @("handoff", "ai-brain", "project-context")
  related_files = @(
    $handoffPath,
    "AGENTS.md",
    "project-context/pointers/000_ai-brain-quick-reference.txt",
    "project-context/pointers/001_handoff-to-brain-workflow.txt",
    "project-context/pointers/002_system-map.json"
  )
  source = "handoff-skill"
} | ConvertTo-Json -Depth 8

Set-Content -Path $payloadPath -Value $payload -Encoding UTF8
python -m local_ai_brain record-artifact --json-file $payloadPath

Notes:
- Do not write directly to localaibrain/brain/brain.db.
- The Local AI Brain command writes scrubbed and distilled copies under localaibrain/brain/artifacts.
- If the handoff is about a specific subsystem, set target_surface to that subsystem name instead of "handoff".
- If the handoff content becomes stale, record a newer handoff rather than editing SQLite.
