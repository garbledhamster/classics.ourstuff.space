# Runtime Git Policy

Decision:
Keep Local AI Brain runtime state local. Track the project-local commander, scripts, agent instructions, installed skill shims, and pointer index.

Track:
- localaibrain.py
- localaibrain/scripts
- AGENTS.md
- project-context/AGENT_ALIGNMENT.md
- .codex/AGENTS.md
- .codex/actions
- .codex/environments
- .agents/skills
- .claude/skills
- project-context/pointers

Ignore:
- localaibrain/brain
- localaibrain/brain/brain.db
- localaibrain/brain/artifacts
- Python __pycache__ folders
- *.pyc and related Python bytecode

Reasoning:
The database and generated brain artifacts are local runtime state. They can contain volatile retrieval records, scrubbed/distilled copies, temp handoff imports, and machine-specific paths. Future agents need the operating convention and pointer map, not a stale database snapshot.

Operational rule:
When durable knowledge should survive between agents, put the short canonical pointer in project-context/pointers and record the full artifact through Local AI Brain. Do not commit the generated database or artifact folders unless the user explicitly asks for a portable brain snapshot.
